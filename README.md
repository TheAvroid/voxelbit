# voxelbit

A voxel world rendered by a raytracer, in a browser tab. No rasteriser, no meshes —
every frame walks rays through a voxel grid on the GPU, with real sun shadows, ambient
occlusion, traced water reflection and refraction, and a denoiser holding it together.

Play it at **[voxelbit.net](https://voxelbit.net/)**, and come talk about it on
**[Discord](https://discord.gg/AtW5fWZtSG)**.

Trees fall where you cut them and break apart on the ground. Water freezes and thaws.
Snow settles voxel by voxel and melts again. The world is infinite, deterministic, and
generated as you walk into it.

## Requirements

**WebGPU.** Chrome or Edge 113+, or any browser with WebGPU enabled. There is no
fallback renderer — if `navigator.gpu` is missing, the game says so and stops.

## Run it locally

```
start.bat                          # Windows: double-click, opens the game
python tools/serve-nocache.py      # or run the dev server yourself
```

Then open **http://127.0.0.1:8080/**. A server is required — `file://` will not work.

The dev server builds the game in memory on every request, so **edit a source fragment
and hit refresh**. There is no build step while you work.

## How it is built

`game/index.html` is a **build artifact**, not source. It is generated by
`tools/bundle.py`, which concatenates the fragments in `src/` in the order given by
`src/manifest.txt`. Read that order as the dependency graph: a fragment may use anything
declared above it and nothing below it.

```
python tools/bundle.py     # src/ -> game/index.html
python tools/lint-vb.py    # checks the artifact is fresh, and a few traps that bite
python tools/vbtest.py     # boots the real game in a browser and diffs it vs a baseline
```

[`docs/architecture.md`](docs/architecture.md) is the map — what every fragment owns, and
the four things in here that do not behave like ordinary code.
